## 1. 본문 (차트 분석 및 매매 기법)

### 하락장 매매 기법
- X ① 400선 눌림에 지지받을때 ② 전고점이 눌림에 지지받을때 (상승중) (붉은색 펜으로 덧씌워진 내용)
- ① 역헤드앤숄더 ABC or ABCDE 패턴
- ② 이빨 3개 어깨선. 100선 매수
- ③ 400선 저점에 매수 (차트: 400선 아래에서 W자 형태의 패턴)
- ④ 400선 근접 수평선 저점에 매수

### 상승장 매매 기법
- X 400선 매매법 돌파 후 하락하는 지지받는대 만약 400선을 터치 안될때는 200선을 매입한다 (붉은색 펜으로 덧씌워진 내용)
- ① 1차눌림은 캔들이 하락하고 장기이평 (우상향) 이 지지 받을때 (하락. 돌파. 지지)
- ② 400선 매매법에서 캔들이 400선 돌파 후 하락하고 지지 받을때
  - 차트: 400선을 돌파했다가 다시 근접하며 저점(Point)을 형성하는 모습
  - 메모: 역배열 400선 돌파 눌림매수
- ③ 1차 상승후 눌림에서 전고점을 긋는다
  - 차트: 캔들이 100선을 돌파한 후 다시 100선 부근 저점에서 매수하는 흐름
- ④ 상승후 전고점이 지지 받을때 매수
  - 차트: 상승 후 이전 고점(전고점) 라인까지 하락했다가 지지받는 매수 타점
  - 메모: 5, 10, 20, 60, 120 (이평선 나열 추정)

### 주요 확인 사항 및 400선 매매
- 1) 200선 추세 확인
- 2) 거래량 확인 거래량이 나오면 눌림에 매수 (전저점. 전고[판독불가])
- 3) 어깨선 매수. 100이평. 2파. 전저점 매수
- 4) 400선 매매 (눌림 매수. 지지받을때. 2번째 돌파할때)
  - 400선 근접에서 선을 긋고
  - 하락 눌림 받을때 (거래량이 나오면 {추정: 800선 | Point}) 매수 찐상승한다
  - 차트: 200선 아래 저점 형성
- 5) 거래량 없는 상승은 곧 하락한다
- 6) 힘이 강한 종목은 (상한가 간종목) 변동성이 커서 횡보할때 저점 매수. 고점 매도 하면서 매매를 한다

### 패턴별 매수 타점 요약
- 400선 매매 차트 묘사:
  - 400선과 200선이 존재
  - 캔들이 200선 아래로 내려가 쌍바닥을 형성할 때 '200선 아래 저점 매수'
  - 박스권 흐름에서 '매수. 고점 매도' 반복
- 하락장 = 1. 3이빨이 나온후 100선 아래
- 상승후눌림 = 쌍바닥이 나오면 매수
- 하락후 횡보에서 저점을 지지 받을때 2바닥 3바닥 할때 매수

## 2. 차트 시각화 (Chart Visualization)

### 방법1: ASCII 그래프 (텍스트 차트)

#### 기호 매핑
- 캔들 흐름: 상승 `/`, 하락 `\`, 횡보 `-`, 저점 `V`, 고점 `^`
- 이평선: 100선 `...`, 200선 `===`, 400선 `###`
- 지지/저항선: `---` (수평선)
- 매수 타점: `(B)` 또는 `*매수*`

#### 패턴1: 200선 아래 쌍바닥 매수
```text
400선  ###############################################
                        \       /
200선  =================\=====/=======================
           \      /       \   /
            \    /         \ /  <-- (B) 200선 아래 저점 매수
             \  /           V   <-- 쌍바닥
              V
```

#### 패턴2: 400선 돌파 후 눌림 지지
```text
          <-- 상승 추세
            /
           /    <-- 400선 돌파
400선  ###--/--###---###--###--###--###
           \       /
            \     /  <-- (B) 눌림 지지 매수
             \   /
              \ /
               V
```

#### 패턴3: 역헤드앤숄더 (하락 반전 패턴)
```text
        <-- 첫 번째 어깨 (L)
       /
      /
100선 .../.../.../.../.../.../.../.../...
        \      <-- 헤드 (H) - 가장 깊은 저점
         \    /
          \  /
           \/
          / \
         /   \  <-- 두 번째 어깨 (R)
        /     \
```

#### 패턴4: 이빨 3개 (하락 3파동)
```text
  /    /    /
 /    /    /
/    /    /
\    /    /
 \  /    /
  \/    /
   \   /
    \ /
     V   <-- 매수 타점
```

### 방법2: 파이썬으로 실제 차트 생성하기

아래 파이썬 코드를 실행하면 실제 캔들 차트 이미지가 생성됩니다.

#### 필수 라이브러리 설치


#### 차트 생성 코드
```python
import pandas as pd
import numpy as np
import mplfinance as mpf

# 1. 가상 데이터 생성 (200선 아래 쌍바닥 패턴 시뮬레이션)
dates = pd.date_range('2023-01-01', periods=80)
np.random.seed(42)

# 기본 가격 흐름: 하락 후 2번의 저점(쌍바닥) 형성 후 상승
base_price = np.linspace(5000, 3000, 20).tolist() + \
             np.linspace(3000, 3800, 15).tolist() + \
             np.linspace(3800, 2900, 15).tolist() + \
             np.linspace(2900, 6000, 30).tolist()

data = {
    'Open': base_price + np.random.normal(0, 50, 80),
    'High': base_price + np.random.normal(100, 50, 80),
    'Low': base_price - np.random.normal(100, 50, 80),
    'Close': base_price + np.random.normal(0, 50, 80),
    'Volume': np.random.randint(1000, 5000, 80)
}
df = pd.DataFrame(data, index=dates)

# 거래량이 실린 찐상승 시뮬레이션 (쌍바닥 이후)
df.loc[dates[50:], 'Volume'] = df.loc[dates[50:], 'Volume'] * 3

# 이평선 데이터 (가상)
df['MA100'] = df['Close'].rolling(window=5, min_periods=1).mean() + 500  # 시각화를 위해 기간 축소 대입
df['MA200'] = df['Close'].rolling(window=10, min_periods=1).mean() + 800
df['MA400'] = df['Close'].rolling(window=20, min_periods=1).mean() + 1500

# 2. 매수 타점 마커 설정 (쌍바닥 저점)
buy_markers = np.full(len(df), np.nan)
buy_markers[19] = df['Low'].iloc[19] - 200
buy_markers[49] = df['Low'].iloc[49] - 200

# 3. 차트 렌더링 세팅
apds = [
    mpf.make_addplot(df['MA100'], color='green', width=1.0, title="100-MA"),
    mpf.make_addplot(df['MA200'], color='blue', width=1.5, title="200-MA"),
    mpf.make_addplot(df['MA400'], color='pink', width=2.0, title="400-MA"),
    mpf.make_addplot(buy_markers, type='scatter', markersize=100, marker='^', color='red')
]

# 4. 차트 출력 (이미지 파일로 저장)
mpf.plot(df, type='candle', style='charles', addplot=apds, volume=True,
         title="Double Bottom under 200 MA (Buy Signal)",
         ylabel='Price', ylabel_lower='Volume',
         savefig='chart.png')  # 이미지로 저장
```

**참고:** 위 코드를 실행하면 `chart.png` 파일이 생성됩니다. 이 이미지를 현재 MD 파일의 동일 폴더에 저장한 후 아래와 같이 MD 파일에 표시할 수 있습니다:

## 3. AI 답변 가이드 (Response Guide)

### 답변 순서 템플릿
1. **시장상태 요약** - 상승장/하락장/횡보장 여부
2. **핵심 근거** - 100선, 200선, 400선, 역헤드앤숄더, 쌍바닥, 거래량 등
