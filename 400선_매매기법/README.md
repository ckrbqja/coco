# 400선 매매기법 차트 자동 생성

## 🚀 한 번에 실행하기

```bash
cd 400선_매매기법
python generate_charts.py
```

## 📋 사전 준비

### 1. 파이썬 설치 확인
```bash
python --version
```

### 2. 필요한 라이브러리 설치
```bash
pip install pandas numpy mplfinance matplotlib
```

## 📊 생성되는 파일

실행하면 다음 파일들이 자동 생성됩니다:

### 차트 이미지 (charts/ 폴더)
- `pattern1_double_bottom.png` - 200선 아래 쌍바닥 매수
- `pattern2_pullback_support.png` - 400선 돌파 후 눌림 지지
- `pattern3_inverse_head_shoulders.png` - 역헤드앤숄더 하락 반전
- `pattern4_three_teeth.png` - 이빨 3개 하락 3파동

### 업데이트되는 파일
- `400선_쌍바닥_매수법.md` - 각 패턴 섹션에 차트 이미지 자동 추가

## 🎯 패턴별 설명

### 패턴1: 200선 아래 쌍바닥 매수
- 하락 후 200선 아래에서 두 번의 저점을 형성
- 쌍바닥(W패턴)이 형성되면 매수 타점
- 거래량 증가와 함께 상승

### 패턴2: 400선 돌파 후 눌림 지지
- 400선을 상향 돌파
- 다시 400선 근처까지 하락(눌림)
- 400선에서 지지받으면 매수

### 패턴3: 역헤드앤숄더 하락 반전
- 하락 후 세 개의 바닥 형성
- 첫 어깨 → 헤드(가장 깊음) → 두 번째 어깨
- 두 번째 어깨 이후 상승 반전

### 패턴4: 이빨 3개 하락 3파동
- 연속 3번 하락 파동
- 각 하락 후 반등이 있지만 점점 더 깊은 저점
- 마지막 저점에서 매수
